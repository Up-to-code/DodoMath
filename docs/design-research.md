# Math interface redesign · 13 October 2026

The private local evidence library is `../duolingo-math-research/index.html`: 72 original assets, 117 screenshot panels from official grade guides, four timed GIFs, and a source/dimension/hash manifest. Reference media is not bundled in the app.

Primary evidence: [Math engineering](https://blog.duolingo.com/developing-math/), [8th-grade examples](https://blog.duolingo.com/8th-grade-math/), [path design](https://blog.duolingo.com/new-duolingo-home-screen-design/), [topic browsing](https://blog.duolingo.com/product-highlights/), [character animation](https://blog.duolingo.com/world-character-visemes/), [sound identity designer](https://ambroseyu.com/work/duolingo-sonic-identity).

Target: a short instruction above a companion speech bubble; one dominant mathematical stage; compact answer controls; safe bottom Check/Continue. Keep original purple navigation, generated original characters, all advanced mathematical answers and sequential method gates. Remove redundant cards, coloured page slabs, and repeated text. The path alternates winding direction and opens a bounded inline node detail. Courses remain separate browsable topics.

Following the user’s image-asset preference, question companions use generated transparent raster pose sheets. Fox is the main mascot; Nia and Orbit support lessons. Four full-body poses change eyes, brows, mouth, and gesture; 160ms crossfades and small root motion connect them. The runtime does not independently rig joints or perform lip sync. Reduced motion preserves facial feedback. No Rive dependency or speaking/lip-sync capability is claimed. Sound effects are original and action-scoped, with tap throttling and user mute. Exact Duolingo artwork/font/audio parity is not claimed.
